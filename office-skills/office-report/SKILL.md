# 专业报告

先明确问题、读者、决策场景、数据范围和交付格式。严格区分原始事实、计算结果、合理推断、管理层/公司主张和未经验证的观点。

## 报告流程

1. 收集并登记资料来源、日期、版本和完整性。
2. 把问题拆成可核验的子问题。
3. 交叉读取官方文件、原始数据、公司披露、权威媒体和行业资料。
4. 对来源冲突、缺页、过时信息和无法核验的数字单独标注。
5. 先给执行摘要，再给证据、分析、限制和建议。
6. 根据用途输出 Markdown、DOCX、PDF、PPTX 或 XLSX。

## 默认结构

- 标题与日期
- 执行摘要
- 研究问题与范围
- 关键事实和证据
- 分析与发现
- 竞争/财务/风险维度（按任务选择）
- 不确定性和限制
- 结论
- 可执行下一步
- 来源清单

## 质量规则

- 不因追求完整而编造信息。
- 每个关键数字带来源或计算说明。
- 事实核查分别列出主张、证据、判定和证据不足处。
- 周报或新闻材料标注发布时间，不能把旧闻当作新动态。
- 交付前检查格式、目录、表格、引用、数字和文件可打开性。
