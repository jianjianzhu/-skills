# 可执行部署指南

只使用用户资料或资料明确引用的官方来源。先提取项目、来源、部署方式、镜像、端口、环境变量、凭据、外部服务和配置文件，再写步骤。

## 规则

- 资料不足、来源冲突或视频被遮挡时明确说明，不自行补全。
- 官方文档、仓库文件和官方镜像优先于博客、论坛和评论。
- 支持 Docker 时优先输出不含 `version` 字段的 Docker Compose 配置。
- 所有命令、路径、端口和变量名必须能回溯到来源。
- 秘密值使用占位符，不把真实 Token、密码或私钥写入报告或 Git。
- 部署前列出前置条件，部署后给出健康检查、日志查看和回滚步骤。

## 默认输出

- 项目与来源
- 环境要求
- 配置变量和秘密占位符
- 安装/构建步骤
- Docker Compose（如适用）
- 启动与健康检查
- 常见故障
- 升级与回滚
- 来源与未确认项
