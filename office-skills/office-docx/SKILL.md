# Word 文档

新建 DOCX 使用 `docx`；读取优先使用 `pandoc -t markdown`；编辑已有 DOCX 时解压并修改 XML，保留原文档结构和格式。

## 工作流程

1. 明确文档类型、读者、页数、格式、是否需要目录/页码/表格/批注/修订。
2. 先搭建标题层级和信息结构，再填充正文。
3. 表格同时设置表格宽度和每个单元格宽度，避免在 Word/Google Docs 中变形。
4. 列表使用编号配置，不把 `•` 直接写入正文。
5. 段落换行使用独立 Paragraph，不使用 `\n` 假装段落。
6. 处理已有文档时先合并 fragmented runs，再做精确修改；不删除用户原有批注和修订。
7. 写入后用 LibreOffice 转 PDF，逐页检查分页、表格、字体、页眉页脚和目录。
8. 必要时运行结构验证，发现问题先修复源文件再交付。

## 交付格式

默认包括：`.docx`、PDF 预览、目录/页码说明和验证结果。合同、正式报告等文件必须保留来源、假设和未核验事项，不能把推断写成事实。

说明：Tabbit 中可检索到的 Word 条目主要是特定网页内容生成故事的提示词，不适合通用文档生产，因此本技能采用本机可验证的 DOCX 工作流。
